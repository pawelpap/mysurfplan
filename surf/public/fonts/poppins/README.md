# Poppins email fonts

Unmodified Google Fonts v24 WOFF2 subsets, downloaded on 13 September 2026.
Regular (400) and bold (700), Latin and extended Latin. The adjacent OFL.txt
contains the copyright notice and SIL Open Font License 1.1.

Source stylesheet: https://fonts.googleapis.com/css2?family=Poppins:wght@400;700&display=swap

Source files:

- poppins-v24-latin-400.woff2: https://fonts.gstatic.com/s/poppins/v24/pxiEyp8kv8JHgFVrJJfecg.woff2
- poppins-v24-latin-ext-400.woff2: https://fonts.gstatic.com/s/poppins/v24/pxiEyp8kv8JHgFVrJJnecmNE.woff2
- poppins-v24-latin-700.woff2: https://fonts.gstatic.com/s/poppins/v24/pxiByp8kv8JHgFVrLCz7Z1xlFQ.woff2
- poppins-v24-latin-ext-700.woff2: https://fonts.gstatic.com/s/poppins/v24/pxiByp8kv8JHgFVrLCz7Z1JlFc-K.woff2
- Licence: https://github.com/google/fonts/blob/main/ofl/poppins/OFL.txt

Email font URLs are public, static and shared by all recipients. No Google font
requests or recipient-specific URLs are added to the emails. Arial is the first
fallback. The website's existing font loading remains separate until B6.
